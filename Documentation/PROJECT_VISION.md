# Project vision

Game 1 is an original, accessible five-stage game inspired by the broad creative and progression ideas of Spore: Cell, Creature, Tribal, Civilization, and Space. Preserve species identity and meaningful player choices across stages; use original assets and expression.

Game 2 explores deeper heritable evolution, ecology, procedural biology, and emergent civilization using appropriate proven foundations. Finish Game 1 before committing to full Game 2 production. The immediate objective is a verified development environment.

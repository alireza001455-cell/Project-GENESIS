# Roadmap

Current milestone: Phase 0. See SOFTWARE_SETUP.md for ordered tasks and acceptance evidence.

1. Phase 0: assessment, engine/tool selection, repository setup, empty-scene build and clean-checkout verification. Gameplay remains gated.
2. Phase 1: Cell Stage, beginning with a narrowly scoped playable milestone after Phase 0.
3. Phase 2: Creature Stage, subject to creature assembly and locomotion feasibility gate.
4. Phases 3–5: Tribal, Civilization, and Space stages.
5. Phase 6: integrated Game 1 release.
6. Game 2: separate research/feasibility and production planning after Game 1 is stable.

No release dates committed. Shared synchronization must first demonstrate a documentation-only exchange before complicated automation is introduced.
